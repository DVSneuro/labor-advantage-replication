# Legacy exploratory work

`initial_exploration/` preserves the repository as it existed before the longitudinal
public-data project was scaffolded on 2026-08-26. These notebooks and outputs are not
inputs to the new pipeline and may contain cached execution errors or manual exports.

Data provenance:

- `data/zhang2022/`: byte-identical files from Zenodo record 7126263 (CC BY 4.0).
- `data/nih_reporter/`: public NIH RePORTER search/API extracts, including public PI
  names. The timestamped search export was manually obtained and is not considered a
  reproducible source artifact; new work must use a scripted API or bulk download.

No proprietary Academic Analytics individual-level files were found in repository
history. Do not use this directory for new analysis.
